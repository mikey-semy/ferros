# Journal — M1: Kernel infrastructure

## 2026-06-26 — M1a: VGA writer + `print!`/`println!`

- Added `src/vga_buffer.rs`:
  - `Color` / `ColorCode` / `ScreenChar` describe the VGA cell format.
  - `Writer` tracks the column, writes to the bottom row and scrolls up (terminal-style).
  - All accesses go through `core::ptr::write_volatile` / `read_volatile` (memory-mapped
    I/O must not be optimized away).
  - Global `WRITER` behind `spin::Mutex` — `Mutex::new` is `const`, so a plain `static`,
    no `lazy_static` needed.
  - `core::fmt::Write` impl → free `{}` formatting; `print!` / `println!` macros.
- `src/main.rs`: `_start` now uses `println!` instead of the raw `0xb8000` loop.
- Dep added: `spin = "0.12"`.
- Behaviour note: output appears on the **bottom** row and scrolls up (like a terminal),
  unlike M0 which wrote to the top-left.
- Panic still just halts; a printing panic handler comes in **M1b** (via serial), to
  avoid the VGA-lock deadlock case.

### Next (M1b)
- Serial (COM1 / `uart_16550`) output + `serial_print!` / `serial_println!`.
- A panic handler that prints the message.
