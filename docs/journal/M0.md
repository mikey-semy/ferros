## 2026-06-26 — First boot achieved ✅

- Installed **QEMU 11.0.50** to `C:\Users\Mike\qemu` and added it to PATH. (winget and
  `-Verb RunAs` elevation couldn't be surfaced from the sandbox — `0x800704c7`; a direct
  `Start-Process` of the installer with a user-approved UAC prompt worked.)
- Hit two recent-nightly changes while building:
  1. Custom `.json` targets now require **`-Zjson-target-spec`** → added under `[unstable]`
     in `.cargo/config.toml`.
  2. The target-spec format tightened (`target-pointer-width` must be a number; disabling
     SSE now also needs **`rustc-abi: "softfloat"`**). Rebuilt `x86_64-ferros.json` from the
     current built-in `x86_64-unknown-none` spec, but with **PIE disabled** (bootloader 0.9
     loads a static, non-PIE kernel) and the default (small) code model.
- `cargo build` + `cargo bootimage` succeed; **`bootloader` 0.9.34 compiles fine on nightly
  1.98** (the feared bitrot didn't happen).
- Booted `bootimage-ferros.bin` in QEMU and captured the framebuffer via the monitor:
  **`ferros booting...`** renders white-on-black. M0 boot goal met.
- Pinned the toolchain to **`nightly-2026-06-26`** for reproducibility.
